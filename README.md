- **Python и API:** FastAPI, Pydantic, HTTP-запросы, интеграция внешних сервисов, структурированные ответы в JSON.

- **Автоматизация и запуск:** n8n, Docker, VPS, Git и GitHub.
- **Проверка качества:** Pytest для API и RAGAS для оценки ответов RAG-ассистента.

## 🚀 Избранные проекты

### [Конкурент.Пульс — анализ материалов конкурентов](https://github.com/Nayalya31/competitor-monitoring-ai)

Мультимодальный MVP, который анализирует тексты, изображения и веб-страницы. Возвращает сильные и слабые стороны, уникальные предложения и рекомендации на русском языке. Для сайтов собирает видимый текст и скриншот через Selenium. Есть веб-интерфейс и desktop-клиент.

**Польза для бизнеса:** помогает маркетологу собрать первичный разбор материалов конкурента и определить направления для улучшения собственного предложения.

**Технологии:** Python · FastAPI · Pydantic · ProxyAPI · Selenium · HTML/CSS/JavaScript · PyQt6.

### [RAG-ассистент по документации](https://github.com/Nayalya31/rag-documentation-assistant)

Ассистент ищет информацию во внутреннем мануале бухгалтерской компании и формирует ответы с опорой на найденные фрагменты. Работает в консоли и Telegram, использует кеш SQLite. Для оценки качества предусмотрен скрипт с метриками RAGAS.

**Польза для бизнеса:** помогает сотрудникам находить нужные инструкции и ответы на повторяющиеся вопросы без ручного просмотра всего документа.

**Технологии:** Python · OpenAI API · ChromaDB · SQLite · python-telegram-bot · RAGAS.

### [Telegram-бот лофт-студии «Луна»](https://github.com/Nayalya31/luna-loft-bot)

Виртуальный менеджер, который отвечает на вопросы о студии, уточняет формат мероприятия, дату, количество гостей и бюджет. Помогает выбрать подходящий вариант и перейти к обращению к администратору. Поддерживает генерацию и редактирование изображений по запросу.

**Польза для бизнеса:** помогает провести первичную консультацию, уточнить потребности клиента и подготовить его к обсуждению заявки.

**Технологии:** Python · pyTelegramBotAPI · GigaChat API · ProxyAPI · HTTPX.
